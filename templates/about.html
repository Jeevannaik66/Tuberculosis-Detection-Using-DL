About TB Detect

A deep learning project for automated tuberculosis screening from chest X-rays, using DenseNet121 classification and Grad-CAM heatmaps.

About the Project

A deep learning-based approach to assist in early tuberculosis screening from chest X-rays

Objective

To build an AI-powered web application that can analyze chest X-ray images and detect signs of tuberculosis, providing quick screening results along with visual explanations of the model's findings.

Training Data

The classification model is trained on publicly available chest X-ray datasets containing both Normal and TB-positive images. The detection model uses the TBX11K dataset with annotated bounding boxes around TB-affected regions.

Disclaimer

This tool is intended for educational and screening purposes only. It is not a substitute for professional medical diagnosis. Always consult a qualified healthcare provider for accurate TB diagnosis and treatment.

How It Works

Our system uses multiple deep learning models working together to analyze chest X-rays for tuberculosis indicators

Upload X-Ray

Step 1

Upload a chest X-ray image in common formats (JPEG, PNG). The system first validates that the image is a valid chest X-ray before proceeding with analysis.

AI Analysis

Step 2

A DenseNet121 deep learning model trained on thousands of labeled X-rays classifies the image as Normal or TB-positive with a confidence score.

Visual Results

Step 3

Grad-CAM heatmaps highlight the regions the model focused on, showing which areas of the X-ray influenced the prediction.

Key Features

What makes this TB detection system useful for screening and analysis

Instant Results

Get classification results within seconds of uploading a chest X-ray. No waiting for manual review — the AI processes and responds in real time.

Visual Explanations

Heatmaps and bounding boxes show exactly where the model detected abnormalities, making results interpretable and transparent for review.

Pre-Check Validation

A separate validation model confirms the uploaded image is a valid chest X-ray before analysis, reducing false results from incorrect inputs.

Technology Stack

Built with proven deep learning architectures and modern web technologies

DenseNet121

Classification Model

A 121-layer convolutional neural network pre-trained on ImageNet, fine-tuned on labeled TB chest X-ray datasets for binary classification.

Grad-CAM

Explainability

Gradient-weighted Class Activation Mapping generates heatmaps showing which areas of the X-ray influenced the model's decision.

Flask

Web Framework

Lightweight Python web framework powering the application backend, with TensorFlow and OpenCV for image processing and inference.

Usage
What image formats are supported?
The system accepts standard image formats including JPEG and PNG. Upload a clear, well-lit chest X-ray image for the best results.
What is a Grad-CAM heatmap?
Grad-CAM (Gradient-weighted Class Activation Mapping) is a technique that highlights the regions of an image that most influenced the model's prediction. Red areas indicate high importance, while blue areas had less influence.
How is this different from a medical diagnosis?
This is a screening tool powered by AI, not a clinical diagnosis. It can flag potential TB indicators quickly, but a confirmed diagnosis requires proper medical testing, sputum analysis, and evaluation by a healthcare professional.
What models are used in the system?
The system uses DenseNet121 for TB classification, a separate pre-check model to validate chest X-ray inputs, and Grad-CAM for generating visual heatmaps of the model's focus areas.
Is my uploaded image stored or shared?
Uploaded images are stored temporarily on the server for processing and are not shared with any third parties. They are used solely for generating the detection results.
